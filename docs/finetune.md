# 검수 마스크를 활용한 Kvasir-SEG 재학습 파일럿

**메디인테크 AI Research Engineer 동계 현장실습 지원 프로젝트**

내시경 용종 검수 앱에서 사람이 확정한 마스크를 기존 PyTorch 분할 모델의 추가 학습에 사용합니다. 두 조건에 사진과 학습 설정을 똑같이 적용하고, 검수 전후 마스크만 바꿉니다. 수정한 마스크가 공개 참조와 더 잘 일치하는지는 별도로 평가합니다.

## Colab에서 실행

1. 검수 앱에서 **결과 내보내기 → 결과 ZIP 다운로드**로 `review_results.zip`을 받습니다. 실제로 변경한 마스크가 있어야 A/B 학습이 진행됩니다.
2. 검수 앱이 **실제로 사용한 `baseline_best.pt`** 파일도 준비합니다.
3. [Google Colab](https://colab.research.google.com/)에 `Kvasir_SEG_Reviewed_Label_Finetune.ipynb`를 올립니다. **런타임 → 런타임 유형 변경**에서 GPU를 선택하고 **모두 실행**을 누릅니다.
4. 파일 선택 창이 뜨면 검수 ZIP을 선택하세요. 기준 모델도 함께 선택할 수 있습니다. 기준 모델이 필요한데 자동으로 찾을 수 없으면 두 번째 선택 창이 나옵니다.
5. 마지막 셀에서 다운로드되는 `kvasir_finetune_results_*.zip`을 풀고 **`RESULTS.md`**를 엽니다. 브라우저 다운로드가 시작되지 않으면 Colab의 파일 탭에서 마지막 셀에 표시된 ZIP 경로를 찾으세요.

같은 런타임에서 작업하면 기본 Colab 폴더와 이전 검수·학습 결과 경로를 검색합니다. 먼저 선택한 ZIP을 바꾸고 싶으면 첫 셀에서 **SELECT_REVIEW_ZIP**에 체크합니다. Drive의 기본 작업 경로를 사용한 경우 **MOUNT_DRIVE**에 체크하고 연결합니다. 업로드 창에서 선택한 파일은 이후 같은 작업 경로에서 재검색합니다.

### 기준 체크포인트 찾기

| 검수 앱이 사용한 모델 | 파일이 있는 곳 |
| --- | --- |
| 기존 분할 실험의 체크포인트 | 처음 분할 실험 ZIP의 `checkpoints/baseline_best.pt` 또는 Colab의 `polyp_audit/runs/…/checkpoints/` |
| 검수 앱에서 이번 실행에 학습한 모델 | Colab의 `kvasir_review/training/…/checkpoints/baseline_best.pt` |
| 검수 앱에서 직접 업로드한 모델 | 당시 올린 원본 파일 또는 `kvasir_review/uploaded/…/` |

위 경로는 기본 설정 기준입니다. 사용 중인 Colab 파일 탭에서 파일 옆 메뉴의 **다운로드**를 선택할 수 있습니다. 계층이 여러 개라면 후보 파일을 먼저 자동으로 검색하는 편이 편합니다. 파일명과 별개로 **검수 ZIP에 저장된 SHA-256과 맞는 가중치만** 사용합니다. 오류 메시지에는 필요한 해시와 확인한 후보가 표시됩니다.

## 실험 설계

| 항목 | 적용 방식 |
| --- | --- |
| A | 실제 사람이 승인하거나 수정한 사진과 **검수 전 후보 마스크** |
| B | **A와 같은 사진**과 **검수 후 확정 마스크** |
| 두 조건 공통 | 동일 시작 가중치, 이미지와 배치 순서, 좌우·상하 반전 및 밝기 증강, 시드, 학습률, 업데이트 횟수 |
| 학습 규칙 | 고정 5 epoch, 배치 4, AdamW, backbone 5×10⁻⁵, classifier 10⁻⁴, BCE 0.5 + soft Dice loss 0.5. 소규모 데이터에 맞춰 BatchNorm의 running statistics를 고정하고 FP32를 사용합니다. |
| 평가 | 기존 테스트셋의 같은 사진에서 이미지별 Dice 및 Boundary F1을 구해 평균합니다. 원래 코드와 같이 모델 격자의 2픽셀을 경계 매칭 허용 거리로 사용합니다. |

검수 앱의 `review_setup.json`으로 해상도, 정규화, 공식 데이터 ZIP 및 분할 해시를 대조합니다. 승인·수정 사례에는 원본 크기의 0/255 PNG 두 장이 있어야 합니다. 보류 사례는 건수에 포함하며 학습에서 제외합니다. 합성·스모크 기록은 연구 모드의 사람 검수에 포함되지 않습니다. 모델 격자에서 사라지는 편집도 추적합니다. 실제 변경이 0건이거나 축소 뒤 두 조건의 마스크가 모두 같으면 재학습 비교 없이 보고서와 CSV를 만듭니다.

두 학습에서 증강한 이미지·유효 영역 텐서의 해시와 실제 배치 ID 순서를 대조합니다. 모델 비교에는 원래 `test` 분할을 사용합니다. 검수 후보인 `val_audit`와 이미지 ID·중복 그룹이 겹치지 않는지 검사합니다. 이 테스트셋은 이전 프로젝트에서 사용됐으므로 **기존 테스트셋을 재사용한 탐색적 비교**입니다. 실험 설정과 5 epoch 종료는 평가 전에 고정합니다. 검수 앱에 원본 체크포인트의 분할 출처가 미확인으로 기록돼 있으면 보고서에도 표시합니다.

### 결과 읽기

- **수정 마스크의 품질** · 실제 수정한 사례에 한해 검수 전후 마스크를 공개 참조와 평가합니다. 이 참조 마스크는 A/B 학습에 쓰이지 않습니다.
- **재학습 모델의 성능** · `B − A`의 양수는 검수 후 마스크 조건의 점수가 더 높았다는 뜻입니다. 동일 이미지의 점수 차이를 묶고 이미지 중복 그룹을 단위로 2,000번 bootstrap해 95% 구간을 냅니다.
- **효과 해석** · 95% 구간에 0이 들어가거나 차이의 절댓값이 0.01 미만이면 효과가 불확실하다고 표시합니다. 0.01은 파일럿 해석용 기준입니다. 구간은 한 시드로 학습한 모델에 조건부이며 임상 효과나 학습 반복 간 변동을 측정하지 않습니다.
- **데이터 범위** · 공개 이미지 유사도 기반 그룹을 사용합니다. 환자나 검사별 독립성은 확인할 수 없습니다. 수동 수정은 사용자 기록으로 해석하며 전문가 합의 여부는 측정 대상에 포함되지 않습니다.

## 결과 ZIP

| 파일 | 내용 |
| --- | --- |
| `RESULTS.md`, `run_setup.json` | 실행 유형, 설정과 해시, 비교 결과, 한계 |
| `reviewed_cases.csv` | 승인·수정·보류 상태, A/B 사용 여부, 원본과 입력 격자의 픽셀 변경 수 |
| `checkpoint_A.pt`, `checkpoint_B.pt` | 매 조건의 고정 종료 시점 가중치 |
| `training_history.csv`, `matched_training_schedule.json` | 손실 추이, 이미지 순서, 증강 텐서 해시, 실제 업데이트 횟수 |
| `test_comparison.csv`, `test_paired_metrics.csv` | 기존 테스트셋의 짝지은 성능과 구간 |
| `reviewed_mask_quality_*.csv`, `figures/*.png` | 라벨 품질과 모델 성능을 구분한 표와 그림 |

이 비교에서 입력과 평가 분할 검사를 통과한 기록만 사용합니다. 변경 마스크가 없어 학습을 생략한 실행은 보고서, 설정, 사례 목록을 저장합니다. 폴더 이름에 실행 해시가 있어 서로 다른 입력으로 만든 결과를 구별할 수 있습니다.

## 검증과 데이터 출처

- **CPU 경로** · Python 3.12, PyTorch 2.9.1+cpu, TorchVision 0.24.1+cpu에서 노트북의 7개 코드 셀을 실행했습니다. 내장 합성 자료 48쌍으로 승인·수정·보류 선별, 마스크 쌍, 두 조건 학습, 동일 5장 평가, 짝지은 구간, 체크포인트와 ZIP 저장을 확인했습니다.
- **기존 앱 호환성** · 기존 앱의 브라우저 테스트에서 내려받은 ZIP과 그 실행의 스모크 체크포인트로 A/B 전체 흐름을 다시 실행했습니다. 원저자 Kvasir-SEG 1,000쌍에서도 기존 빈 검수 ZIP의 분할을 확인하고 학습을 생략했습니다.
- **예외 경로** · 승인·보류만 있는 ZIP은 체크포인트 없이 요약을 내보냈습니다. SHA-256이 다른 체크포인트, 평가 분할의 ID, 원본과 다른 PNG 크기, 0/255 외의 마스크 값은 학습 전에 차단됐습니다.
- **예시 실행 ZIP** · 합성 사례에 0으로 초기화한 테스트용 가중치를 사용했습니다. Colab에서 첫 셀의 `PROFILE=smoke`를 선택하면 별도 입력 없이 같은 형태의 CPU 예시를 만들 수 있습니다. 예시 수치는 구현 점검용입니다.
- **실제 실습에서 확인할 범위** · 이번 후속 실험에서 사용자의 실제 검수 기록과 Colab GPU의 업로드·학습은 실행하지 않았습니다.

공식 Simula 배포와 원저자 Kaggle v3 경로를 지원합니다. 검수 단계에서 사용한 데이터 ZIP의 SHA-256을 우선하며, 공식 경로에서 같은 버전을 받기 어려우면 첫 셀의 `LOCAL_ARCHIVE`에 보관 중인 원본 ZIP 경로를 적을 수 있습니다.
