# Kvasir-SEG 용종 마스크 검수

**메디인테크 AI Research Engineer 동계 현장실습 지원 프로젝트**

기존 PyTorch 용종 분할 모델을 사용해 공개 내시경 영상의 검수 순서를 만들고, 검수자가 브라우저에서 후보 마스크를 승인·수정·보류하는 Colab 앱입니다. 합성 주석 오류를 이용한 오프라인 순위 비교와 수동 검수 기록을 한 실행에서 생성합니다.

## 시작하기

1. `Kvasir_SEG_Review_Colab.ipynb`를 [Google Colab](https://colab.research.google.com/)에 업로드합니다.
2. **런타임 → 런타임 유형 변경 → GPU**를 선택하고 **모두 실행**을 누릅니다.
3. 마지막 셀에 출력된 주소를 열고, 같은 셀의 사용자 이름 `reviewer`와 임시 암호로 로그인합니다.
4. **승인**, **수정**, **보류** 중 하나를 선택합니다. 수정은 **수정 → 브러시 또는 지우개 → 수정 미리보기 → 수정본 저장** 순서입니다.
5. **결과 내보내기**를 누르고 활성화된 **결과 ZIP 다운로드**로 `review_results.zip`을 받습니다. 검수 도중에도 내보낼 수 있습니다.

Colab에서는 Gradio의 임시 공유 연결에 세션마다 생성한 암호를 적용합니다. 공개 Kvasir-SEG 연구 영상 전용으로 사용하세요. 노트북을 공유하기 전 실행 출력을 지워 임시 로그인 정보가 함께 전달되는 일을 방지하고, 검수를 마치면 런타임을 종료합니다. [Gradio 연결과 인증 안내](https://gradio.app/guides/sharing-your-app), [Gradio 6.32.0](https://pypi.org/project/gradio/6.32.0/)

### 이전 모델 가져오기

기존 노트북과 같은 Colab 런타임이면 `/content/polyp_audit/runs/` 및 기본 Drive 작업 경로에서 호환 가능한 `baseline_best.pt`를 찾습니다. 새 런타임이면 첫 셀 설정의 **UPLOAD_CHECKPOINT**에 체크하고, 실행 중 파일 선택 창에서 `baseline_best.pt`를 선택하세요. Colab 파일 탭으로 먼저 올렸다면 자동 탐색을 사용하거나 `CHECKPOINT_PATH`에 파일 경로를 설정할 수 있습니다.

가능하면 이전 결과 ZIP의 `run_setup.json`과 `split_manifest.csv`도 같이 선택하세요. 설정이 있으면 체크포인트의 실행 ID, 입력 해상도, 정규화, 정책과 데이터 분할을 대조합니다. 체크포인트만 제공하면 모델 구조와 출력 모양을 확인하며, 학습 때 사용한 분할은 미확인으로 표시합니다. 파일은 PyTorch의 `weights_only=True`로 읽습니다. 화면 상단에 실제 모델 출처와 검증 선택 epoch를 표시합니다.

호환 파일이 없으면 TorchVision COCO 사전학습 LR-ASPP MobileNetV3-Large에 이진 분할 헤드를 적용해 기존 기준 모델을 학습합니다. 학습 700장과 체크포인트 선택 100장을 사용하며, 기본 해상도는 256×256, 학습은 12 epoch입니다. GPU가 없을 때도 이미 학습한 체크포인트로 추론할 수 있습니다. `PROFILE="smoke"`는 합성 데이터 48쌍, 1 epoch로 전체 실행을 점검합니다. [TorchVision LR-ASPP API](https://docs.pytorch.org/vision/0.24/models/generated/torchvision.models.segmentation.lraspp_mobilenet_v3_large.html)

### 작업 중단과 복구

- **같은 런타임에서 다시 열기** · 마지막 셀을 다시 실행하거나 검수 페이지를 새로고침합니다. 미완료 사례부터 이어갑니다. 확정한 판단은 SQLite에 기록되며, 일시적인 PNG 쓰기 오류가 있을 경우 다음 시작·내보내기에서 DB의 바이트로 복원합니다.
- **런타임 교체 후 재개** · 첫 검수 전에 `MOUNT_DRIVE=True`를 설정합니다. 세션은 `MyDrive/kvasir_review/sessions/`에 저장됩니다. 재실행할 때 같은 모델과 데이터 설정을 유지하세요. 업로드한 체크포인트는 Drive의 작업 폴더에서 재사용할 수 있으므로 이후 `UPLOAD_CHECKPOINT=False`로 실행해도 됩니다. Drive의 동일 세션은 한 런타임에서 편집하세요.
- **런타임 종료 전 작업 받기** · 기본 런타임 로컬 저장소에서 작업하는 경우, 종료 전에 ZIP을 내려받으세요. 결과 ZIP은 검수 결과를 전달하는 용도이고, 검수 재개에는 원래 세션의 DB와 추론 캐시가 사용됩니다.
- **연결 또는 다운로드 오류** · 검수 링크가 만료되면 마지막 셀을 다시 실행합니다. ZIP 버튼을 사용할 수 없으면 Colab 파일 목록의 `kvasir_review/sessions/<세션>/review_results.zip`을 확인합니다. 데이터 서버에 접속하지 못하면 공식 ZIP을 업로드하고 첫 셀의 `LOCAL_ARCHIVE`를 설정합니다.

## 검수와 오프라인 실험

| 구분 | 입력과 지표 |
| --- | --- |
| **앱 검수 목록** | `val_audit` 영상의 원본·좌우·상하·복합 반전 예측을 되돌려 평균합니다. 평균 확률의 엔트로피 중 상위 5% 평균이 이미지 점수입니다. 확률 0.50의 후보 마스크는 letterbox 패딩을 제거한 뒤 원본 크기로 되돌립니다. 검수 화면은 영상, 모델 후보, 엔트로피를 사용합니다. |
| **기존 주석 점수** | 후보와 모델 마스크의 합집합에서 불일치 픽셀에 `0.75 × 확신도 + 0.25 × 엔트로피`를 곱한 평균입니다. |
| **새 경계 점수** | 후보·모델 양쪽 윤곽의 최근접 거리 중 상위 25%를 방향별로 평균합니다. 거리를 8 모델 픽셀에서 잘라 정규화하고, 이 윤곽 성분 65%와 기존 점수 35%를 섞습니다. 양쪽 마스크가 비면 윤곽 성분은 0, 한쪽만 비면 1입니다. |

후속 실험은 작은 이동, 약한 침식·팽창, 국소 누락을 고정 시드로 주입합니다. 마스크가 완전히 사라지거나 변경량이 원래 전경의 35%를 넘으면 원래 후보로 되돌립니다. 실제로 변경된 후보만 오류로 집계합니다. 모든 방식이 같은 후보를 보고, 점수별 순위를 저장한 뒤 주입 정보를 결합합니다. 12회 같은 이미지를 재사용하며, 각 반복에서 500개 무작위 순위와 10·20·30%의 동일 건수를 비교합니다.

기존에 탐색한 `val_audit`를 재사용한 **탐색적 비교**입니다. 점수 식을 사전에 고정했고 기존 최종 테스트셋은 이번 실험에서 사용하지 않습니다. 참조 마스크는 후보 생성과 오프라인 평가에만 쓰입니다. 후속 실험 수치는 새로 계산합니다. 공개본에서 환자·검사 세션 ID를 확인할 수 없어 기존 중복 그룹 분할에는 이미지 유사도를 사용합니다.

## 결과 파일

| 파일 | 내용 |
| --- | --- |
| `REVIEW_REPORT.md` | 검수 상태별 건수, 실제 검수 기록이 있을 때의 경과 시간, 합성 실험 요약 |
| `review_log.csv` | 사례 ID, 순위·점수, 승인·수정·보류, 사유, 경과 시간, 마스크 위치 |
| `masks/before/`, `masks/after/` | 원본 크기의 이진 PNG. 승인과 수정에서 최종본을 저장합니다. 보류에는 후보 마스크를 보존합니다. |
| `review_queue.csv`, `review_setup.json` | 검수 우선순위, 설정, 원본 데이터와 모델 출처, 분할 해시 |
| `offline_experiment/` | 합성 후보의 순위·주입 정보, 예산별·유형별 CSV와 비교 그래프 |

검수 시간은 사례를 표시한 순간부터 결정을 제출할 때까지의 경과 시간입니다. 자리 비움도 포함될 수 있으며, 비교 검수 없이 시간 절감 효과를 평가할 수 없습니다. 합성 스모크 모드의 버튼 테스트는 사람 검수 집계에서 제외됩니다. 이 프로젝트의 평가 범위는 공개 연구 데이터이며 임상 성능을 측정하지 않습니다.

## 전달 전 검증

- **CPU 스모크 테스트** · Python 3.12, PyTorch 2.9.1+cpu, TorchVision 0.24.1+cpu, Gradio 6.32.0에서 8개 코드 셀을 실행했습니다. 합성 데이터 48쌍으로 체크포인트가 없는 경우의 1 epoch 기준 모델 학습과 합성 오류 실험까지 확인했습니다.
- **로컬 Chromium 브라우저** · 인증 로그인, 오버레이 표시 전환, 브러시·지우개, 미리보기 후 수정 저장, 승인·보류, 빠른 중복 클릭, 새로고침 후 재개, 중간 ZIP 내보내기와 실제 파일 다운로드를 검사했습니다. 내보낸 마스크는 원본 픽셀 크기의 0/255 PNG였고, 브라우저의 세 가지 테스트 판단은 사람 검수 0건으로 분리됐습니다. 앱을 다시 실행한 뒤 기록과 마스크 파일을 복구했습니다.
- **공개 영상 통합 점검** · 원저자 Kaggle v3 배포본 1,000쌍과 기존 96×96 축소 CPU 기준 모델을 사용했습니다. 분할 메타데이터가 일치하는 체크포인트를 불러와 검수 후보 100장과 새 합성 실험 산출물을 생성했습니다.
- **Colab에서 추가로 확인할 범위** · 이번 확장본의 실제 Colab GPU 학습, Gradio 임시 공유 연결과 Drive 마운트, 실제 사용자 검수는 실행 검증 범위에 포함되지 않았습니다.

## 지원서 요약과 60초 데모

> 공개 내시경 데이터 Kvasir-SEG와 PyTorch 용종 분할 모델을 활용해 후보 마스크의 검수 순서를 제시하고, 검수자가 브라우저에서 마스크를 승인·수정·보류하도록 구현했습니다. 검수 기록과 원본 크기의 수정 마스크를 내보낼 수 있도록 했으며, 경미한 합성 주석 오류에서 동일한 검수 예산으로 기존 점수와 새 경계 점수, 무작위 순위를 비교하는 평가를 구성했습니다.

1. **0–15초** · 첫 사례의 원본, 후보 마스크, 불확실성 시각화를 보이고 해당 사례가 우선 표시된 이유를 설명합니다.
2. **15–35초** · 마스크의 누락 영역을 칠하고 과한 영역을 지웁니다. 수정 미리보기를 확인한 뒤 사유와 함께 저장합니다.
3. **35–50초** · 기록을 ZIP으로 내보내 `review_log.csv`와 원본 크기의 수정 마스크를 보여줍니다.
4. **50–60초** · 합성 오류 그래프의 같은 검수 예산을 가리키고, 합성 비교와 실제 검수 기록의 의미를 설명합니다.
