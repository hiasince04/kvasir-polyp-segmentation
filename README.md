# 내시경 용종 분할 모델의 실패 분석과 불확실성 기반 마스크 검수

공개 내시경 영상 데이터셋인 Kvasir-SEG에서 용종 분할 모델이 실패하는 사례를 분석합니다. 판단이 필요한 영상을 먼저 보여주는 검수 앱에서 사람이 후보 마스크를 승인·수정·보류하고, 저장한 마스크로 이어서 학습하는 비교 실험을 실행할 수 있습니다.

## Colab 실행 순서

| 단계 | 노트북 | 생성하는 파일과 다음 단계의 입력 |
| --- | --- | --- |
| 1. 모델 학습과 실패 분석 | [연구 노트북](notebooks/Kvasir_SEG_Research.ipynb) · [상세 안내](docs/research.md) | 연구 결과 ZIP과 `checkpoints/baseline_best.pt`. 검수 단계에서 체크포인트와 연구 ZIP의 `run_setup.json`, `split_manifest.csv`를 재사용할 수 있습니다. |
| 2. 후보 마스크 검수 | [검수 앱 노트북](notebooks/Kvasir_SEG_Review_Colab.ipynb) · [상세 안내](docs/review.md) | Gradio에서 후보를 승인·수정·보류한 뒤 **결과 내보내기**로 `review_results.zip`을 받습니다. 앱이 실제로 사용한 `baseline_best.pt`도 보관합니다. |
| 3. 검수 전후 라벨 비교 | [재학습 노트북](notebooks/Kvasir_SEG_Reviewed_Label_Finetune.ipynb) · [상세 안내](docs/finetune.md) | `review_results.zip`과 검수에 쓴 체크포인트를 불러옵니다. 같은 사진의 검수 전후 마스크로 각각 이어서 학습해 Dice와 Boundary F1을 비교하고 결과 ZIP을 생성합니다. |

1. [Google Colab](https://colab.research.google.com/)에서 사용할 `.ipynb`를 엽니다. 저장소에 접근할 수 있으면 **파일 → 노트북 열기 → GitHub**에서 찾아 열거나, 파일을 내려받아 **업로드** 탭에서 엽니다.
2. **런타임 → 런타임 유형 변경**에서 GPU를 선택하고 **모두 실행**을 누릅니다. 각 단계의 첫 셀에서 실행 옵션을 고를 수 있습니다.
3. 검수 노트북의 마지막 셀에 표시된 앱을 열어 로그인합니다. 수정할 사례는 브러시나 지우개로 편집하고 미리보기 후 저장합니다. 검수 진행 중에도 결과를 내보낼 수 있습니다.
4. 런타임을 바꾸기 전에 결과 ZIP과 체크포인트를 내려받거나 Drive에 저장합니다. 새 런타임에서는 필요한 파일을 업로드할 수 있습니다. 실제로 달라진 마스크가 없으면 3단계는 현황을 요약하고 A/B 재학습을 생략합니다.

## 실행 및 검증 기록

- **분할 연구** · Colab Tesla T4에서 Kvasir-SEG 1,000쌍을 사용했습니다. 테스트 100장의 기준 모델 Dice는 0.841이었습니다. 별도 검증 분석셋에서 20장을 확인하는 조건으로 시뮬레이션한 결과, 불확실성 순위는 분할 실패 4건을 발견했고 무작위 순위의 평균은 2.35건이었습니다. 경계 손실을 변경한 모델의 전체 Dice 차이는 −0.006이었고, 95% 구간에는 0이 포함됐습니다.
- **검수 앱** · 공개 영상의 검수 후보를 생성하고, 브라우저에서 마스크 편집·저장, 중복 클릭, 중단 후 재개, ZIP 다운로드를 테스트했습니다.
- **재학습 비교** · 합성 CPU 스모크 테스트에서 검수 파일을 읽고 두 조건을 학습해 같은 평가 사진으로 비교한 뒤 결과 ZIP을 생성했습니다. 실제 수동 수정본으로 학습한 GPU 비교 결과는 아직 확인되지 않았습니다.

## 데이터 출처

노트북은 실행 시 Kvasir-SEG를 다운로드합니다. 공식 이용 조건에 따라 연구·교육 목적으로 사용하며 상업적 사용에는 사전 서면 허가가 필요합니다. 영상과 참조 마스크, 모델 가중치, 검수 파일은 실행 환경에서 관리합니다. [Simula 데이터셋과 이용 조건](https://datasets.simula.no/kvasir-seg/) · [Jha et al., 2020](https://doi.org/10.1007/978-3-030-37734-2_37)
